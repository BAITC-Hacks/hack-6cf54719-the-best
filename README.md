# Платформа учебных задач от компаний

Платформа, на которой компании публикуют реальные задачи для студентов, а студенческие команды предлагают решения и прототипы. Компания рассматривает отклики и вручную выбирает исполнителя.

## Как это работает

1. Компания регистрируется, описывает задачу и готовит карточку к публикации.
2. AI-помощник помогает уточнить описание и заполнить поля карточки. Компания проверяет и подтверждает предложенные изменения.
3. Студенческие команды находят задачи в каталоге, используют фильтры и отправляют отклики со своим решением или прототипом.
4. Компания рассматривает отклики и сама принимает решение о выборе команды.

AI помогает сформулировать информацию, но не придумывает факты и не выбирает исполнителя.

## Возможности MVP

- Регистрация и роли «Компания» и «Студент».
- Создание, редактирование и публикация карточек задач.
- Рейтинг готовности карточки, показывающий, насколько полно описана задача.
- Каталог задач с фильтрами.
- Отклики студенческих команд с описанием решения и ссылками на прототипы.
- Просмотр откликов и ручной выбор исполнителя компанией.
- AI-помощник для уточнения формулировок и заполнения карточки с подтверждением со стороны компании.

## Технологии

- **Backend:** Python, FastAPI — REST API и автоматическая документация OpenAPI.
- **База данных:** PostgreSQL.
- **Frontend:** пока не выбран.
